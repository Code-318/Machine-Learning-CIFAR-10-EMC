# CIFAR-10 Image Classification CNN Report

## Introduction

This project aims to create a convolutional neural network (CNN) which is capable of categorising images by content from the CIFAR-10 dataset. There are 10 categories, containing images of objects such as modes of transport and animals. By processing the images through the layers of the neural network, the model is able to calculate a set of weights, representing how likely an image from CIFAR-10 is to be any of the 10 categories.
